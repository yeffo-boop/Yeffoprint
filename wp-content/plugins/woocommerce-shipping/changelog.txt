= 2.3.14 - 2026-08-17 =
* Tweak - Force-bundle the @wordpress/ui package in webpack so the build stays correct even if the package stops opting out of script externalization.

* Tweak - Upgrade WooCommerce Components and Data packages to remove the vulnerable DOMPurify 2.5.8 dependency.

* Tweak - WooCommerce 11.0 Compatibility.

* Tweak - Hide the customs product details fields and show an explanatory notice when the content type is Documents, since document mailings don't include a customs item declaration.
